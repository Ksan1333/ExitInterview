# Exit Interview 0.1.3

2人のつなぎ方を合言葉にした版です。設定は要りません。

- タイトルの「遊ぶ」で、2人が同じ合言葉を入れると同じ部屋につながります。先に入れた人が部屋を作って待ち、あとの人がそこに入ります。
- 前と同じ合言葉を入れれば、続きから遊べます（部屋は 30 日で消えます）。3人目は入れません。
- 合言葉はスマホの中でハッシュにして送るので、サーバーに言葉は残りません。全角と半角、前後の空白は区別しません。
- 「部屋を作る」「部屋に入る」と4桁の番号、0.1.2 の「サーバーの合言葉」はなくしました。
- ゲームの中身は 0.1.2 と同じです。

## Exit Interview について

- 2人用の脱出ゲーム（3ステージ、目安は 90〜120 分）。別々のスマホから同じ部屋に入り、通話しながら遊びます。
- 1台で操作を確かめられるテスト部屋つき。
- Android 8.0 以上。

## 確かめたこと

- 持ち主の PC で `gradlew lintRelease distApk`（JDK 17）が通り、配布用の APK ができること（Android 8.0 で使えない API の呼び出しなし）。
- APK が配布用の鍵で署名されていること（APK Signature Scheme v2、証明書の SHA-256 `4c0bc0e2e3bcc25ad59213d5b57d1b6c28cede824fd9f4a7975759b68e22f080`。0.1.0 と同じ鍵）。版 0.1.3（versionCode 4）、minSdk 26。
- APK の `assets/server_base.txt` にサーバーのアドレスだけが入り、鍵が入っていないこと。`assets/server.txt` は空。
- `server/test_server.py`（Python 3.12）：63 件すべて通過。合言葉の部屋（作る・入る・戻る・3人目は断る・別の合言葉は別の部屋・期限切れは作り直す・2人が同時に入れても 1 部屋）を、メモリ版と DynamoDB のモックの両方で。
- アプリと同じコード（`RoomClient`・`HttpTransport`）で、鍵を設定した手元のサーバー（`server/local_server.py`）につなぎ、2人が同じ合言葉で同じ部屋に入ること、前の版の鍵つきの要求も通ることを確認。
- `tools/enginecheck`（部屋の番号が決まった値になること）と `tools/typecheck/run.sh` が通ること。
- タイトル・合言葉の画面・待つ画面・テスト部屋・設定を Robolectric で描き、目で確かめたこと。
